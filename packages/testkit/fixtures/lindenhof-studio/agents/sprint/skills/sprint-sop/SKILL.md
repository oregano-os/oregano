# Sprint SOP

Read the relevant workflow before explaining its current step. The workflow
files own sequencing, routing, timing and approvals. Company Records own
source evidence. Company Tools compute views and presentation. This Skill
provides wording and participant guidance; it grants no execution authority.

For Friday Close, use the exact reply template in
[assets/friday-update-template.md](assets/friday-update-template.md).
Count only authenticated replies in the run's persisted shared thread.
Every included Contributor appears once in the factual completeness report.
No scores, rankings or inferred reasons describe people. The Monday handoff
reads current board data, without carrying Friday plans into a new run.
