# Property campaign workflow template

1. A responsible human decides whether the property should be marketed.
2. The agent prepares landing-page and creative drafts from verified facts.
3. A responsible human approves each exact artifact.
4. Restricted Tools publish only approved artifacts.
5. A responsible human supplies the exact budget and duration.
6. A restricted Tool launches the exact campaign after approval.
7. The agent reads normalized facts and proposes reversible optimization.
8. A responsible human decides which assets continue or stop.

The receiving Workspace must select roles, risks, Tools, grants, language,
templates, and policy. The Company Instance must bind provider-neutral
Capabilities to exact Connectors.
