# Property campaign SOP

- Use only verified property facts.
- Maintain stable identifiers for every draft and variant.
- Treat a changed draft, asset set, budget, or duration as a new approval input.
- Keep provider-specific fields out of the Workspace workflow.
- Record Capability and Connector evidence for every external effect.
