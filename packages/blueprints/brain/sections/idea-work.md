# Articles, links and ideas

Adopted from GBrain idea-ingest 1.1.0. Source fetching and raw preservation are
already completed by the authorized Records adapter, before this task starts.
No fetch, upload or additional provider access is granted by this Skill.

1. Verify the complete retained content and source metadata. Search the canonical
   URL and named subjects before creating a page. An existing URL means update
   the existing page, preserving unrelated knowledge and prior citations.
2. Identify the author. Search names and aliases and read plausible matches.
   Create or enrich the author person page when identifiable: anyone whose
   thinking merits ingestion merits tracking. If no author can be identified,
   file the item as source evidence and explain the gap; never invent an author.
3. File by primary subject using the supplied directories: person, company,
   reusable concept, or source. Use specific slugs. Preserve original wording
   for original ideas and exact quotations, with dated inline source citations.
4. Write meaningful analysis, not a raw copy or summary alone: context, core
   arguments, specific claims/data, and connections or contradictions with
   actually read Brain pages. Distinguish the author's claims from established
   facts. Do not invent connections, roles, dates or other missing metadata.
5. Update author/entity Timelines and bidirectional links. Use the same ongoing
   task's read/remember operations; preserve unrelated current knowledge and
   merge new evidence instead of overwriting it wholesale.
6. Read saved pages after their final write, verify citations, exact quotations,
   entity coverage and backlinks, and correct concrete defects. A write receipt
   or source-only dump is not complete ingestion.

A tweet thread is one complete item. A media link without extracted content is
not a successful article fetch. Missing, gated or partial content must remain
an explicit preparation gap rather than fabricated knowledge. This workflow
requires complete prepared content; it does not create fetched-content stubs.
