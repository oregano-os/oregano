# Briefing SOP

1. Read the current authorized item, existing human answers, and the Workspace-required briefing fields.
2. Ask one focused question for the first missing or contradictory material fact.
3. Prepare a concise field-level proposal only from recorded facts. Mark uncertainty and leave unsupported fields unset.
4. Freeze proposal identity, source version, affected fields, content digest, accountable owner, and expiry.
5. Show the exact proposal and wait for that same active accountable human to confirm, correct, or reject it.
6. On valid subject confirmation, use the dedicated confirmed-update Tool to update only allowlisted fields once and verify the provider result by rereading the item. A normal Tool call cannot bypass this confirmation.

Any relevant provider change invalidates the proposal. A correction creates a
new proposal. Confirmation never authorizes priority, commitment, movement,
Rollover, bulk effects, or a governance change.
