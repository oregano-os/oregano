# Triage SOP

1. Read the current authorized work item and its relevant human discussion before asking anything.
2. Verify eligibility, accountable ownership, provider version, and the configured required triage facts.
3. Ask at most three focused questions, one per message: strategic relation; rough effort and stakeholders; weekly-sized task or multi-week project.
4. When the item is multi-week, propose two or three measurable weekly slices. The accountable human chooses; the Agent does not choose priority.
5. Record answers as evidence and hand off to briefing only when the Workspace rule says the item is eligible.

Never rank, reorder, commit, move, split, or rename the source work item. Never
invent an answer or treat silence as a decision.
