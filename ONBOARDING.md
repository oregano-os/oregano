# CompanyOS onboarding entrypoint

Canonical, maintained onboarding lives under [`docs/onboarding/`](docs/onboarding/README.md).

For a new or newly received Company Workspace:

1. read `docs/onboarding/README.md` and
   `docs/onboarding/company-workspace.md`;
2. use the exact Core and Workbench version declared by the Workspace;
3. run `companyos onboard <workspace>`;
4. follow every blocking or accountable manual step reported by the command.

The July 2026 Stage 1 provider runbook previously stored here is frozen in Git
history. It is not a current CompanyOS setup contract and must not be executed
without revalidation through the canonical onboarding process.
