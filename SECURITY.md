# Security policy

Do not report vulnerabilities, exposed credentials, or customer data in a
public issue. Use GitHub's private vulnerability reporting for this repository.

Supported stable releases receive security corrections when a fix is feasible.
Prereleases and unreleased source may change without compatibility guarantees.

Never commit provider credentials, database URLs, private keys, customer
identifiers, or real Company Workspace content to this repository. Revoke an
exposed credential before attempting history cleanup.
